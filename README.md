# Aarya Shah, Portfolio

React + Vite portfolio. No backend, no API keys. Fonts: Instrument Sans and JetBrains Mono via Google Fonts.

## Run locally
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs /dist
npm run preview
```

## Add your details (required before submitting)
Open `src/config.js` and fill in `email`, `linkedin`, `github` and any project URLs. Empty values stay hidden or show as "not added yet".

## GitHub
```bash
git init && git add . && git commit -m "Portfolio"
git branch -M main
git remote add origin https://github.com/<your-username>/<repo>.git
git push -u origin main
```
Make the repo **Public**.

## Deploy free on Vercel
1. vercel.com → sign in with GitHub → Add New Project → import the repo.
2. Framework preset: Vite (auto). Click Deploy.
3. Your URL looks like `https://<project>.vercel.app`.
